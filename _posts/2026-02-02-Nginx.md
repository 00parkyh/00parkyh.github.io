# 🌐 Nginx

## 1. Nginx란?

Nginx는 **차세대 웹 서버**로 불리며, 가볍고 여러 개의 접속을 동시에 처리하는 데 특화된 오픈소스 서버 소프트웨어입니다. <br>
과거의 강자였던 Apache의 단점을 보완하며 등장했습니다.

### 💡 핵심 배경 (C10K 문제)

과거에는 "어떻게 하면 1만 개의 클라이언트 접속(Connection 10,000)을 동시에 처리할 것인가?"가 큰 숙제였습니다. Apache는 접속마다 프로세스/스레드를 생성해 메모리 부족 현상이 생겼지만, **Nginx는 적은 자원으로 이를 해결**했습니다.

---

## 2. Nginx의 핵심 구조 (Architecture)

Nginx가 왜 빠른지 이해하려면 **이벤트 기반(Event-Driven)** 구조를 알아야 합니다.

- **Master Process:** 설정 파일을 읽고, 유효성을 검사하며 Worker Process를 관리합니다.
- **Worker Process:** 실제로 클라이언트의 요청을 처리합니다.
    - **Event-Loop 방식:** 한 개의 프로세스가 끊임없이 이벤트를 확인하며 요청을 처리합니다. 작업이 완료될 때까지 기다리지 않고 다음 요청을 받으므로 효율이 극대화됩니다.

---

## 3. 주요 기능 (Main Features)

### ① 정적 콘텐츠 서비스 (Web Server)

HTML, CSS, JavaScript, 이미지 파일 등 변하지 않는 파일을 클라이언트에게 직접 빠르게 전달합니다.

### ② 리버스 프록시 (Reverse Proxy)

클라이언트와 백엔드 서버(Java, Node.js, Python 등) 사이에서 중개자 역할을 합니다.

- **보안:** 내부 서버의 IP를 숨길 수 있습니다.
- **버퍼링:** 클라이언트의 느린 연결을 Nginx가 대신 잡아주어 백엔드 서버의 부담을 줄입니다.

### ③ 로드 밸런싱 (Load Balancing)

여러 대의 백엔드 서버로 트래픽을 분산시켜 서버 부하를 방지합니다.

- **알고리즘:** Round Robin(순차적), Least Connections(연결 적은 쪽), IP Hash 등.

### ④ SSL/TLS 암호화 (HTTPS)

HTTPS 인증서를 Nginx에 설정하여 데이터 전송을 암호화합니다. 백엔드 서버가 일일이 복호화하지 않아도 되게끔 도와줍니다.

---

## 4. Nginx vs Apache 한눈에 비교

| **구분** | **Nginx** | **Apache** |
| --- | --- | --- |
| **구조** | Event-Driven (비동기) | Multi-Process / Thread (동기) |
| **자원 사용** | 적은 메모리로 대량 접속 처리 | 접속마다 스레드 생성, 리소스 소비 큼 |
| **확장성** | 모듈을 컴파일 시 포함해야 함 | 동적 모듈 로딩 지원 (유연함) |
| **용도** | 리버스 프록시, 로드 밸런서, 정적 파일 | 다양한 기능의 복잡한 웹 애플리케이션 |

---

## 5. 기본 설정 파일 구조 (`nginx.conf`)

```jsx
http {
    upstream backend_servers {
        server 127.0.0.1:8080; # 백엔드 서버 주소
        server 127.0.0.1:8081;
    }

    server {
        listen 80;
        server_name yourdomain.com;

        location / {
            # 리버스 프록시 설정
            proxy_pass http://backend_servers;
            proxy_set_header Host $host;
        }

        location /static/ {
            # 정적 파일 경로
            root /var/www/html;
        }
    }
}
```

## 6. 결론 : Nginx를 왜 써야 할까?

1. **빠르다 :** 가벼운 이벤트 루프 방식 덕분입니다.
2. **안정적이다 :** 많은 요청에도 메모리 사용량이 일정합니다.
3. **다재다능하다 :** 웹 서버, 프록시, 로드 밸런서 역할을 하나로 수행합니다.
